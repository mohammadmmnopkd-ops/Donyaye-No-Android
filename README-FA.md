## 🤖 تعریف گروه هوش مصنوعی
گروه هوش مصنوعی، مدیر/دستیار اختصاصی مالک بازی است؛ وظیفه‌اش تحلیل وضعیت بازی،
پیدا کردن خطاها، پیشنهاد به‌روزرسانی و بهبود تعادل بازی و آماده‌سازی برنامه تغییرات است.
اعمال تغییرات حساس روی کد و استقرار نهایی باید با تأیید پنل مدیریت انجام شود.
رمزها فقط سمت سرور بررسی می‌شوند و نباید داخل APK قرار بگیرند.

- پنل گروه AI: تحلیل، عیب‌یابی، برنامه‌ریزی به‌روزرسانی و بررسی تعادل بازی.
